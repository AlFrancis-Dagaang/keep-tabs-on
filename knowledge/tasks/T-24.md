# T-24: Mark goals done

## Acceptance criteria
- [x] Mark done: a nullable `done_at` column on goals (one additive migration, applied to dev only after the DB host check). "Mark done" and "Reopen" are in the row actions on Goals and on the goal page; Reopen clears it. A done goal shows a "Done" pill, and done goals list below open ones (deadline order inside each group). Marking done is manual only: reaching or passing the target never does it
- [x] Drops out: a done goal is left out of the Set aside page, including its Total, and out of Overview's Goals list. Its own page still shows its figure and its linked transfers. Reopening brings it back to both
- [x] No side effects: marking done or reopening changes no account balance, no transfer, no other goal and the goal's own figure. A DB-backed test on dev proves that, and that the Set aside rows and Total skip a done goal and count it again once reopened
- [x] `pnpm lint`, `pnpm test` (DB test run 3 times) and `pnpm build` pass; `docs/brief.md` and `docs/design.md` mention done goals where they describe goals; looked signed in on dev at 390px and desktop

## Findings
- Goals row actions are `RowActions` buttons (Edit, Remove), not a dropdown. "Row menu" = one more button there, no new menu component.
- A goal's figure is `goalSetAside` (lib/set-aside.ts); it does not read `done_at`, so the figure stays untouched by design.
- Queries to touch: `app/(app)/goals/page.tsx`, `app/(app)/goals/[id]/page.tsx`, `app/(app)/page.tsx` (Overview Goals), `loadSetAsideRows` (goal query).
- Lessons applying: check DB host (2026-11-14), DB test timeout and 3 runs (2026-11-17), qualify outer table if raw SQL is added (2026-11-17), tick criteria when done (2026-11-13). Show-figure-on-real-data applies lightly: the Set aside Total changes for done goals (see questions).

## Left out
- Auto-done on reaching the target; a "Done goals" filter or archive page; a done date shown anywhere (the column only drives the pill and sort).
- Any change to balances, transfers, `goalSetAside`, the pixel bar or its completion flash.
- Dropping the dead goalId branches in activity/page.tsx and accounts/[id]/page.tsx (separate cleanup).
- Production migration (only when the owner deploys; this task touches dev only).
