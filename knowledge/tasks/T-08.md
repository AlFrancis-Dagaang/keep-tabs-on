## Findings
- `app/(app)/page.tsx` is a placeholder. Everything it needs already exists: `loadBalances` (balances, net worth), the bills/goals/debts queries on their pages, `manilaMonth` and `budgetFor` (T-07), `PixelBar` + `progressBlocks`, and the Overdue badge on Bills.
- Owner decisions (2026-11-13): accounts show as **tiles on the Overview only** (backlog item 7; the Accounts page stays a table), and a **5th card, budget left this month**, is added because the brief's core loop names it.
- Income/expenses this month are sums of `transactions.date` (a plain date) inside the Manila month, so no timestamp is read back (SQL-timestamp lesson OK). Upcoming bills reuse the Bills page's paid-this-cycle join, which compares `created_at` to `cycle_start` in SQL, as the lesson asks.
- Empty states today: most pages say what to do. These only say "No … yet": Settings categories, Activity with a type filter, the debt and goal detail histories, and Budget when no category has a limit (totals just read ₱0).
- T-07 showed `grid-cols-3` with big numbers overflows at 375px, so the cards wrap (2 per row on phones).
- No `prototypes/`. Not cross-cutting, so the graph wasn't used.

## Plan

### 1. Pure money logic, `lib/money.ts` + `lib/money.test.ts` (criterion 1)
- [x] `monthTotals(month, entries)` → `{ income, expenses }`: income and expense entries whose `date` is in the month; transfers don't count; bill and debt payments count as expenses (money out). Uses the existing `nextMonth` helper. Test: first and last day count, the next month's 1st doesn't, transfers ignored.
- [x] `billsDueSoon(bills, today, days = 7)` → `{ count, left }`: bills with `nextDueDate <= today + 7` (overdue included), `left` = sum of `amount − paid this cycle`. Test: overdue counted, day 7 counted, day 8 not, partial payment lowers `left`.

  `shortcut:` note: the bills/goals/debts queries are copied from their pages; move them to `lib/` if a third page needs them.
- [x] No accounts: one empty state ("Add your first account in Accounts…") instead of the page, since every section needs one.
- [x] Five stat cards (`grid-cols-2 sm:grid-cols-3 lg:grid-cols-5`), each a link: Net worth → /accounts; Income this month → /activity?type=income; Expenses this month → /activity?type=expense; Bills due in 7 days (₱ left, "N bills") → /bills; Budget left (`budgetFor(...).left`, red when negative, "No limits set" when budget is 0) → /budget.
