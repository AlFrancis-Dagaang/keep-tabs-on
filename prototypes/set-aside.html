What to judge Two separate bars on each item: Set aside (clay, from linked transfers) and Paid (dark, from Pay / Add money only). They are never added. A full Set aside bar does not mark anything done. Worked example (sample): rent ₱10,000. You transferred ₱3,000 + ₱2,000 to your holding account and linked both to Rent: Set aside ₱5,000. You then paid ₱2,000 from holding: Paid ₱2,000. Rent shows 5,000 set aside and 2,000 paid. Not 7,000.
